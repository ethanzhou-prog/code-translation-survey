# README

- **data.xlsx** contains the quality assessment results for 31 gray-literature (arXiv) studies, including criterion-level scores, total scores, and final inclusion/exclusion decisions based on the predefined quality threshold.
- **Data-items** contains the data extraction records for the 125 selected primary studies, organized according to the research questions (RQs) and covering bibliographic information, programming languages, translation motivations, technical approaches, datasets, and evaluation metrics.
